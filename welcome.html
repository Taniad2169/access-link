3Paste it into your platform

Choose your provider. Always use the site-wide custom code area (Head), not a single-page embed box. Some platforms only allow custom code on paid plans with a connected domain.

Wix
  1. Open your Wix dashboard → Settings.
  2. Scroll to Advanced → Custom Code → + Add Custom Code.
  3. Paste your code, name it "WebSwan Accessibility + Cookies".
  4. Add code to pages: All pages, Load code once. Place code in: Head.
  5. Click Apply and publish your site.
  6. In Wix, also turn on Settings → Cookie banner / Privacy & Cookies settings so Wix's own trackers follow consent.
WordPress
  1. Install the free plugin WPCode (Plugins → Add New → search "WPCode").
  2. Go to Code Snippets → Header & Footer.
  3. Paste your code in the Header box and click Save Changes.
  4. WordPress.com sites need a Business plan or higher to add custom code.
GoDaddy
  1. Websites + Marketing: Edit website → Settings → Site-wide code, paste your code in the Head section, then Publish.
  2. Other GoDaddy builders: add an HTML section to each page and paste the code there.
  3. Also turn on GoDaddy's own Cookie banner setting so their built-in trackers follow consent.
Square Online
  1. Open Square Online → Website → Settings → Tracking tools (or Site-wide custom code on newer plans).
  2. Paste your code in the Header area and save.
  3. If not available on your plan, add an Embed code section to your pages and paste it there.
  4. Publish your site.
Squarespace
  1. Settings → Advanced → Code Injection.
  2. Paste your code in Header and click Save.
  3. Code injection requires a Business plan or higher.
Shopify
  1. Online Store → Themes → ⋯ → Edit code.
  2. Open theme.liquid and paste the code right before </head>.
  3. Click Save. Also set up Shopify's Customer privacy settings.
Webflow, Framer, Duda, Weebly
  1. Open Site settings → Custom code.
  2. Paste your code in Head code (or Header) and save.
  3. Publish the site.
AI website builders (Lovable, Bolt, v0, Base44, Replit, Hostinger AI and others)
  1. Tell the builder: "Add this script tag to the <head> of every page of my website, exactly as written."
  2. Paste your code.
  3. Publish, then open your live site to confirm the ♿ and 🍪 buttons appear at the bottom.
Custom HTML website
  1. Open each page (or your shared header template).
  2. Paste the code just before </head>.
  3. Upload the files to your host.

How to check it worked: open your live website in a private window. You should see the cookie banner, the blue ♿ button at the bottom right and the small 🍪 button at the bottom left.
